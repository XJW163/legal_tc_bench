# LegalTC v1.7.2 — Restored-Span Accounting and Definition-Alias Normalization

Version: `1.7.2`  
Placeholder strategy: `occurrence-unique-retry-quality-gate-v5`  
Controlled-translation schema: `1.4`

## Purpose

v1.7.2 is the final calibration patch for the safe placeholder pipeline. It keeps strict placeholder inventory checks and glossary fallback, while removing two systematic false-positive classes observed in the five-document pilot:

1. legitimate repeated canonical renderings generated by two different source occurrences in legal definition structures;
2. redundant translated-full-form/placeholder wrappers around defined abbreviations or aliases.

The occurrence validator and term-memory format are unchanged.

## 1. Restoration-span accounting

The restored quality gate no longer treats two nearby copies of the same canonical rendering as an error merely because punctuation and quotation marks separate them.

Each restored placeholder records an exact target span:

```json
{
  "placeholder": "【术语0005_02】",
  "term_id": "T0005",
  "canonical_translation": "基本工资",
  "start": 10,
  "end": 14
}
```

All canonical occurrences that overlap a recorded restoration span are accounted for. Therefore the following legal structures are accepted:

```text
基本工资。“基本工资”在本协议第3(a)节中具有所列含义。
控制权变更。“控制权变更”是指……
（以下简称“遣散费”）。遣散费将分两期支付。
```

The gate still rejects deterministic corruption such as:

```text
主体主体
基本工资基本工资
《国内税收法典《国内税收法典》》
```

New diagnostics:

```text
ADJACENT_RESTORED_CANONICAL_DUPLICATION
legitimate_definition_repetitions
legitimate_definition_repetition_count
restoration_span_count
```

## 2. Definition-alias normalization

Alias normalization now operates at term level. When any occurrence of a term is a validated `DEFINIENDUM`, sibling occurrences of that term may be normalized when they form an immediate full-form/alias wrapper.

Supported forms include:

```text
canonical（“placeholder”）
canonical（placeholder）
placeholder（canonical）
placeholder（“canonical”）
allowed_variant（placeholder）
placeholder（allowed_variant）
```

Optional Chinese title marks are preserved:

```text
《联邦存款保险法》（“【术语0019】”）
→ 《联邦存款保险法》
```

Other examples:

```text
【术语0004】（薪酬委员会）
→ 薪酬委员会

现有董事会（【术语0024】）
→ 现有董事会
```

Risky variants are never accepted for alias normalization.

New row-level fields:

```text
definition_alias_normalizations
definition_alias_normalized_occurrence_count
legitimate_definition_repetitions
legitimate_definition_repetition_count
```

New document/manifest statistics:

```text
definition_alias_normalized_paragraphs
definition_alias_normalized_occurrences
legitimate_definition_repetition_paragraphs
legitimate_definition_repetition_pairs
```

## 3. Strict behavior retained

v1.7.2 does not relax the following conditions:

- missing placeholder;
- duplicated placeholder;
- unknown placeholder;
- canonical wording directly attached to a placeholder outside an approved definition-alias pattern;
- nested title marks;
- risky-variant/canonical adjacency;
- semantic-verifier rejection;
- fallback glossary noncompliance.

True inventory failures continue to use safe glossary fallback.

Use a new experiment name because the placeholder strategy changed from `v4` to `v5`.

## Expected pilot direction

Based on the v1.7.1 rejection audit, the expected direction is:

```text
placeholder_restored_rejections:       30 → near 0
placeholder_context_rejections:        10 → near 0
placeholder_fallback_paragraphs:       25 → approximately 6
placeholder_regeneration_attempts:     35 → lower
```

Actual values remain model-output dependent. Genuine inventory failures should continue to fall back rather than be forced through the placeholder path.
